Privacy Policy

Last updated: October 2026

1. Zero telemetry

File Inspector does not collect, store, log, or transmit any personal data, browsing history, download contents, or identifiable telemetry to any external server. Every check runs entirely on your device.

2. Local storage only

The extension may use chrome.storage.local only to keep a short list of recently intercepted download URLs and their SHA-256 references for your own review. This data never leaves your browser and can be cleared anytime from extension settings or Chrome’s storage controls.

3. Permissions explained

The downloads permission is required so the extension can pause risky transfers. Host permissions are used solely to read link URLs and the first few bytes of a file for signature checks. No other data is accessed.

4. Third-party scanners

Optional links to VirusTotal, Jotti, MetaDefender, or similar services open in a new tab only when you click them. File Inspector never uploads files or URLs automatically. Those services are governed by their own privacy policies.

5. No accounts, no tracking

There is no signup, no analytics, no advertising identifiers, and no third-party scripts that phone home. The extension stays silent except when it surfaces a warning to you.

6. Changes & contact

If this policy is updated, the revision date above will change. Continued use after an update constitutes acceptance of the revised policy. Questions about privacy can be raised via the support channel on the Chrome Web Store listing for File Inspector.
