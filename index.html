Binary header scan

Checks MZ magic numbers (0x4D 0x5A) so renamed .exe files can’t hide behind fake extensions.

Instant intercept

Local only

How it works

  1. 01

    You click a download

    The extension reads the target URL and file type in the background.

  2. 02

    Risky files are paused

    Executables and high-risk formats are held so you can inspect the link first.

  3. 03

    You decide

    Copy the URL for VirusTotal or similar, cancel, or proceed if you trust the source.
